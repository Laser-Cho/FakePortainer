사용자별로 아이디 패스워드 따로 만들어서 회원가입 하고 그 사용자별로 로그인 해서 수행하는 모든 작업을 사용자의 접속 IP 해당 작업 시간과 같이 병기해서 기록한다.
모든 사용자 작업 내역을 한 화면에서 볼 수 있는 "사용자 작업 내역" 페이지를 만든다. 
계정 생성 시 비밀번호 복잡도 설정을 넣는다. (영대/소문자, 특수문자, 숫자 3가지 이상 조합 8개, 유효기간 90일) 의 조건이 있으며, 따라서 계정 정보를 기록하는 곳에 계정 생성시간을 같이 기록해서  로그인 할 때 시간이 90일 초과했다면 비밀번호 재설정을 할 수 있도록 만든다. 
회원가입 시, 계정 생성 시  실명 입력과 이메일 입력을 같이 받도록 한다. 
로그인 할 때 비밀번호 연속 5회 실패 시 세션을 종료한다. 

시스템 로그 기능을 보유한다.
사용자, 관리자 접속 기록을 저장한다. 시간, ip, 사용자 를 모두 기록한다. 
서버 로그인 실패, 접근 실패 기록을 모두 기록한다. 
사용자 권한 부여, 변경, 삭제 기록을 모두 기록한다.
관리자 혹은 특수 권한 접근 실패 기록을 모두 기록한다.
기타 이벤트 로그를 모두 기록한다.

관제하고 있는 전 서버의 모든 도커 목록과 상태를 전달하는 api 를 만든다.
